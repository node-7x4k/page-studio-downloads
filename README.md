# Page Studio downloads

Page StudioのMac・Windows版アプリを配布しています。製品紹介・対応環境は [公式サイト](https://page-studio.pages.dev/) をご覧ください。

[バージョン0.7.6のダウンロード](https://github.com/node-7x4k/page-studio-downloads/releases/tag/v0.7.6)

ZIPを展開してアプリを起動してください。Mac版はAppleの公証を受けておらず、Windows版はコード署名をしていません。Windows版の実機操作確認は進行中です。各ファイルのSHA-256はReleaseに掲載しています。
